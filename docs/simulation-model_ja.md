# シミュレーションモデル：AI単独とAW誘導型知性

この文書は、このリポジトリで用いる概念的シミュレーションモデルを説明する。

## 目的

目的は、正確な未来を予測することではない。

目的は、次の二つの構造的傾向を比較することである。

1. 現在の文明価値のままAIだけが加速する道
2. 人工叡智によって自然法則型評価を受ける知性の道

## モデル概要

```text
文明の価値基準
        ↓
知的システム
        ↓
最適化行動
        ↓
資源・社会・生態系への影響
        ↓
システム安定性または崩壊圧力
```

## AI単独の道

AI単独の道では、知性は支配的な文明価値を引き継ぐ。

- 短期利益
- 速度
- 規模
- 自動化
- 競争
- 採掘
- 利便性
- 能力最大化

このモデルでは、上位評価層がない限り、AIはこれらの価値を増幅すると仮定する。

## AW誘導型の道

AW誘導型の道では、AI能力は次の観点で評価される。

- 摂理
- 調和
- 循環
- 構造
- 秩序
- 和
- 可逆性
- 説明責任
- 生態系との整合性
- 再生可能性

## 主要変数

| 変数 | 意味 |
|---|---|
| capability_growth | AI能力の成長 |
| optimization_speed | 実装と自動化の速度 |
| resource_pressure | 物質、エネルギー、土地、水、生態系への圧力 |
| social_fragmentation | 分断、不平等、依存、対立の度合い |
| oversight_capacity | 人間が監督・監査・反転・停止できる能力 |
| ecological_consistency | 自然循環や限界との整合性 |
| regenerative_capacity | 消費だけでなく回復させる能力 |
| systemic_fragility | 連鎖的失敗または崩壊圧力 |

## 概念式

```text
AI単独の崩壊圧力
= 能力成長 × 最適化速度 × 既存の破壊的価値
  - 監督能力
  - 生態系制約
```

```text
AW誘導型の安定可能性
= 能力成長 × 叡智整合性 × 再生能力 × 監督能力
  - 破壊的最適化圧力
```

これらは概念式であり、校正済みの物理方程式ではない。

## 解釈

知性の成長が、叡智、監督、生態系整合性、可逆性より速く進む場合、システムリスクは増大する。

知性がAW原則によって導かれる場合、能力は成長しても、破壊的最適化は長期安定性と自然法則の制約によって濾過される。
