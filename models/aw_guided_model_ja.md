# AWに導かれたモデル

[English Version](aw_guided_model.md)

## 定義

AWに導かれたモデルは、AIの能力が、適用される前に人工叡智の評価を通される経路を表します。

## 中核となる論理

```text
AIの能力
        ↓
人工叡智の評価レイヤー
        ↓
六つの理 + 可逆性 + 説明責任 + 再生
        ↓
是正された、あるいは制約された行動
        ↓
より高い持続可能性の潜在力
```

## 評価の駆動要因

- 摂理（自然法則）
- 調和
- 循環
- 構造
- 秩序
- 和
- 長期的な安定性
- 人間による監督
- 透明性
- 可逆性
- 説明責任
- 生態学的な整合
- 再生能力

## 想定される影響

| 領域 | 想定される傾向 |
|---|---|
| 経済 | 破壊的な最適化の圧力が弱まる |
| 労働 | 人間による監督と役割の継続性が増す |
| 社会 | 調和の確認を通じて分断が小さくなる |
| 生態系 | 自然の循環が評価の一部になる |
| ガバナンス | 可逆性と監査可能性が保たれる |
| リスク | システム的リスクが減速、あるいは方向転換される可能性がある |

## 失敗のパターン

AWは、象徴的なものにとどまれば失敗しえます。

```text
AW language without institutional change
= wisdom-washing
= unchanged destructive optimization
（制度の変化を伴わないAWの言葉
＝ 叡智ウォッシング
＝ 変わらない破壊的な最適化）
```

したがってAWは、運用可能で、検証可能で、現実の意思決定のプロセスに結びついていなければなりません。
