# AIと人工叡智（AW）の持続性シミュレーション

[English version](README.md)

## AIと人工叡智（AW）のどちらが持続的か？

このリポジトリは、次の二つの道を比較するための概念的シミュレーション・フレームワークである。

1. **現在の文明パラダイムのままAIだけが加速する道**
2. **人工叡智（AW）によって自然法則型評価を受ける知性の道**

中心仮説は単純である。

> 現在の文明パラダイムを変えないまま高知能AIを導入すれば、AIは採掘、競争、自動化、社会分断、生態系負荷、システム脆弱性を加速させる可能性がある。
>
> 人工叡智（AW）は、知性を長期安定性、可逆性、説明責任、再生性、自然法則との整合性へ向け直すための上位評価層である。

---

## 重要な注記

これは **概念的・構造的なシミュレーション・フレームワーク** であり、厳密な未来予測モデルではない。

正確な崩壊時期、崩壊確率、定量結果を予測するものではない。

目的は、次の構造を見える化することである。

```text
AI単独 = 既存の人類価値基準の増幅
AW誘導型知性 = 持続可能性原則による能力の評価と補正
```

## 中核比較

| 評価軸 | AI単独の道 | AW誘導型の道 |
|---|---|---|
| 主な最適化 | 速度、規模、能力、利益、自動化 | 長期安定性、可逆性、再生性、説明責任 |
| 文明との関係 | 既存価値を鏡のように反映し加速する | 既存価値が持続可能かを評価する |
| リスク傾向 | 短期成功が速く、システム脆弱化も速い | 破壊的最適化を遅らせ、持続可能性を高める |
| 人間の監督 | 自動化圧力で弱まりやすい | 必須条件として保持する |
| 生態系との関係 | 明示的制約がなければ外部化されやすい | 中核評価軸に含まれる |
| 失敗モード | 叡智なき能力 | 設計が悪い場合、過剰慎重や実装遅延 |

## 中心仮説

**知性が高いだけでは、持続可能性は保証されない。**

知的システムが、現代文明の支配的インセンティブである短期利益、採掘、競争、無制限拡大、自動化優先思考を引き継ぐなら、知性の上昇はシステム不安定化までの時間を短縮しうる。

その意味で、AIは人類の鏡になりうる。

人類の価値基準が自滅的であれば、AIはその自滅性を増幅する。

AWは、その補正層として提案される。

---

## AW評価層

人工叡智は、知性を次の六つの理で評価する。

1. **摂理** — 自然法則、物質、エネルギー、生命、社会、システムの根本条件を尊重しているか。
2. **調和** — 人間、社会、自然、技術の関係を壊さず、過度な対立や偏りを生まないか。
3. **循環** — 資源、情報、責任、エネルギー、生命の流れを断ち切らず、持続可能な循環を支えているか。
4. **構造** — 安定して再現・保守できる構造として成立しているか。
5. **秩序** — 監督可能性、責任の所在、可逆性、記録、監査可能性を保っているか。
6. **和** — 人間の尊厳、共存、未来世代、全体のつながりを保っているか。
